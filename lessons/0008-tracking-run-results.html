Урок 8: Оновлення забігу (Update) та відстеження результату

Вітаю з продовженням! Минулого разу ми зупинилися на тому, що ваш застосунок успішно навчився розпізнавати старт гри та зберігати новий запис про забіг (Run) у базу даних. Це крутий етап!

Але забіг колись закінчується: або перемогою, або поразкою (смертю). І нам потрібно оновити створений запис у базі даних, щоб зафіксувати isVictory та підрахувати duration (тривалість).

1. Збереження ID забігу та часу старту

Щоб оновити запис у БД, нам потрібно знати його id. Метод create в Prisma повертає створений об'єкт. Отже, у нашому LogReaderService ми можемо отримати цей ID у блоці .then((run) => { ... }) та зберегти його у змінну класу (наприклад, currentRunId).

Також, щоб підрахувати тривалість, нам потрібно зберегти час старту (наприклад, використовуючи Date.now()) у змінну currentRunStartTime.

2. Реалізація методу update

Зараз у RunsService (файл runs.service.ts) метод update просто повертає рядок. Вам потрібно замінити його на виклик Prisma. Для оновлення запису використовується this.prisma.run.update(), якому треба передати об'єкт з властивостями where: { id } та data: updateRunDto.

3. Пошук події "Game Over"

Ми не знаємо точно, як гра логує смерть персонажа або перемогу. Це завдання для вас!

Перевірка знань: Як найкраще підрахувати тривалість забігу в секундах, якщо у нас є `startTime = Date.now()` та `endTime = Date.now()`?

Ваше практичне завдання:

Ніякого копіпасту, лише ваші власні навички:

  1. Оновіть src/runs/runs.service.ts: реалізуйте метод update(id: number, updateRunDto: UpdateRunDto) використовуючи Prisma.
  2. В src/log-reader/log-reader.service.ts додайте дві нові змінні класу: currentRunId: number | null = null та currentRunStartTime: number | null = null.
  3. Коли забіг успішно зберігається (в .then(run => ...)), збережіть run.id у currentRunId і поточний час у currentRunStartTime. Підказка: Переконайтесь, що ви приймаєте параметр run у колбеку then.
  4. Реверс-інжиніринг: Запустіть гру, почніть новий забіг і спеціально помріть. Подивіться в консоль терміналу (де виводяться всі рядки логу) і знайдіть рядок, який з'являється при смерті (наприклад, він може містити слово "Game Over" або "Death").
  5. Додайте у парсер перевірку на цей рядок (можна через data.includes('Ваш знайдений рядок')). Коли він зустрічається:
    • Переконайтесь, що currentRunId існує.
    • Підрахуйте тривалість у секундах.
    • Викличте this.runsService.update(this.currentRunId, { isVictory: false, duration: ... }).
    • Після оновлення обнуліть currentRunId та currentRunStartTime.

Після виконання завдання спробуйте зіграти забіг, померти, і перевірити базу даних, чи оновився ваш запис (з'явилась тривалість). Напишіть "готово", якщо вийшло!
