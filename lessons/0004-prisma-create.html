Урок 4: Додавання даних (Метод create)

Ми навчилися читати дані, тепер давайте навчимося їх створювати.

Об'єкт data

Щоб створити запис, ми використовуємо метод create(). У нього ми завжди передаємо об'єкт із властивістю data, яка містить усі необхідні поля нашої моделі.

async create(createRunDto: CreateRunDto) {
  return this.prisma.run.create({
    data: {
      seed: createRunDto.seed,
      isVictory: createRunDto.isVictory,
      duration: createRunDto.duration,
      userId: createRunDto.userId,
      characterId: createRunDto.characterId,
    }
  });
}

Магія DTO та TypeScript

Оскільки ви вже створили CreateRunDto і він ідеально збігається з полями, які очікує Prisma (а саме — містить ідентифікатори userId та characterId), ми можемо передати DTO напряму!

async create(createRunDto: CreateRunDto) {
  return this.prisma.run.create({
    data: createRunDto,
  });
}

Це працює, тому що Prisma розуміє: якщо ви передаєте userId (число), це означає, що ви хочете просто записати зовнішній ключ (Foreign Key). Це найпростіший і найшвидший спосіб.

Альтернатива: Вкладене створення (Nested Writes)

Коли ви будуватимете складніші API, можливо, ви захочете одночасно створити нового Користувача і його Забіг в одному запиті. Prisma вміє і це! Це робиться через спеціальне слово create або connect (якщо запис вже існує) замість передачі ID безпосередньо:

// Приклад (не для вашого поточного DTO, просто для розуміння):
this.prisma.run.create({
  data: {
    duration: 1200,
    isVictory: true,
    user: {
      connect: { id: 1 } // Або create: { username: "Новий Гравець" }
    }
  }
});

Джерело: Документація Prisma Nested Writes

Перевірка знань: Чому ми обгортаємо поля в об'єкт `data: { ... }`, а не передаємо їх одразу в `create(...)`?

Ваше практичне завдання:

  1. Оновіть метод create() у файлі runs.service.ts так, щоб він зберігав дані в базу за допомогою this.prisma.run.create().
  2. Передайте ваш об'єкт createRunDto прямо в поле data.

Після збереження файлу напишіть "готово", і ми обговоримо останні штрихи CRUD!
