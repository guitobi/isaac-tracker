Урок 6: Регулярні вирази та парсинг подій

Чудово! Лог-рідер працює і виводить сирі рядки з гри. Тепер наша задача — перетворити цей потік тексту на структуровані дані, які ми згодом зможемо зберегти в базу через Prisma.

1. Визначення ключових рядків

У логах Isaac нас цікавлять конкретні події. Для початку навчимося розпізнавати старт гри та сід:

  • Рядок сіду: [INFO] - RNG Start Seed: 6CGD EXXV (4016262579) [New, 1]
  • Рядок персонажа: [INFO] - [Frame: 0] Initialized player with Variant 0 and Subtype 0

2. Складання Регулярних Виразів (RegEx)

Для пошуку та вилучення даних ми використаємо регулярні вирази в JavaScript.

Парсинг сіду:

Сід в Isaac складається з 8 символів (літери та цифри), розділених пробілом посередині (наприклад, 6CGD EXXV).

const seedRegex = /RNG Start Seed: ([A-Z0-9]{4} [A-Z0-9]{4})/;

Тут дужки ([A-Z0-9]{4} [A-Z0-9]{4}) створюють групу захоплення (capturing group). За допомогою методу line.match(seedRegex) ми зможемо дістати саме значення сіду.

Парсинг персонажа:

Для визначення персонажа нам потрібні числа після Variant та Subtype:

const playerRegex = /Initialized player with Variant (\d+) and Subtype (\d+)/;

Тут (\d+) захоплює одне або більше цифрових значень для варіанту та субтипу.

3. Як отримати значення в JS/TS?

Метод String.prototype.match() повертає масив, де першим елементом (індекс 0) йде весь знайдений рядок, а наступними (індекс 1, 2 і т.д.) — значення з груп захоплення:

const match = line.match(seedRegex);
if (match) {
  const seed = match[1]; // "6CGD EXXV"
  console.log(`Знайдено сід: ${seed}`);
}
Перевірка знань: Що міститиме змінна `match[2]` після виклику `line.match(playerRegex)` для рядка: "Initialized player with Variant 0 and Subtype 3"?

Ваше практичне завдання:

Важливо: пишіть код самостійно, без копіювання.

  1. У файлі log-reader.service.ts всередині методу tail.on('line') додайте перевірку рядка двома регулярними виразами (для сіду та для персонажа).
  2. Якщо знайшли сід — виводьте в консоль: "🌱 Знайдено сід: {seed}".
  3. Якщо знайшли ініціалізацію гравця — виводьте: "👤 Ініціалізовано гравця. Варіант: {variant}, Субтип: {subtype}".

Коли оновите код — запустіть гру, почніть забіг і переконайтеся в консолі, що виводяться лише ці повідомлення. Після цього пишіть "готово"!
