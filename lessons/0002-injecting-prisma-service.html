Урок 2: Впровадження та використання PrismaService

Я подивився у ваш код і побачив, що у вас вже чудово налаштований PrismaService в папці src/prisma/! Це ідеально. Тепер ми маємо його використати.

Інжект сервісу в контролери/інші сервіси

У NestJS ми отримуємо доступ до інших сервісів через конструктор (це і є Dependency Injection). Відкрийте ваш файл src/runs/runs.service.ts.

Зараз він виглядає як заглушка. Давайте додамо туди PrismaService:

import { Injectable } from '@nestjs/common';
import { PrismaService } from '../prisma/prisma.service';
import { CreateRunDto } from './dto/create-run.dto';

@Injectable()
export class RunsService {
  // 1. Інжектимо PrismaService через конструктор
  constructor(private readonly prisma: PrismaService) {}

  async findAll() {
    // 2. Використовуємо згенеровані методи Prisma Client!
    return this.prisma.run.findMany();
  }
}

Завдяки тому, що Prisma генерує типи безпосередньо з вашої schema.prisma, коли ви наберете this.prisma.run., ваш редактор підкаже вам всі доступні методи (findMany, create, update тощо) і типи даних, які вони повертають.

Перевірка знань: Як NestJS розуміє, який саме сервіс потрібно передати в конструктор?

Ваше практичне завдання:

Перейдіть у файл src/runs/runs.service.ts (я бачу, він у вас відкритий) та:

  1. Додайте PrismaService в конструктор.
  2. Перепишіть метод findAll() так, щоб він повертав список усіх забігів з бази (через this.prisma.run.findMany()).
  3. Змініть метод findOne(id: number), щоб він шукав забіг за ID: this.prisma.run.findUnique({ where: { id } }).

Коли ви це зробите і збережете файл, напишіть мені в чат "готово", і ми перевіримо, як воно працює!
