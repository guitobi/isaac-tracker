Урок 5: Фонові процеси та читання файлів (Tailing)

Я знайшов ваш log.txt! Він знаходиться за адресою: C:\Users\Administrator\Documents\My Games\Binding of Isaac Repentance\log.txt.

Зараз він містить лише інформацію про запуск і вимкнення гри, але коли ви почнете грати, туди посиплються рядки типу RNG Start Seed: ....

Як читати файл, що постійно оновлюється?

В NodeJS ми можемо прочитати весь файл одразу через fs.readFileSync. Але гра дописує лог постійно. Нам потрібен механізм, який називається tailing (від команди tail -f в Linux). Він "слухає" кінець файлу і реагує тільки на нові рядки.

Найпростіший спосіб це зробити в Node.js — використати готову бібліотеку tail.

Інтеграція в NestJS

Ми створимо окремий LogReaderService (або додамо логіку у ваш RunsService, але краще дотримуватися принципу єдиної відповідальності). Ми використаємо інтерфейс OnModuleInit, щоб почати слухати файл одразу при запуску бекенду.

import { Injectable, OnModuleInit } from '@nestjs/common';
import { Tail } from 'tail';

@Injectable()
export class LogReaderService implements OnModuleInit {
  onModuleInit() {
    const logPath = 'C:/Users/Administrator/Documents/My Games/Binding of Isaac Repentance/log.txt';
    const tail = new Tail(logPath);

    tail.on('line', (data) => {
      console.log("Новий рядок з гри:", data);
      // Тут ми будемо парсити регулярними виразами!
    });

    tail.on('error', (error) => {
      console.error('Помилка читання логу:', error);
    });
  }
}
Перевірка знань: Чому краще використовувати бібліотеку типу `tail`, а не просто ставити `setInterval`, який кожну секунду читає файл за допомогою `fs.readFile`?

Ваше практичне завдання:

  1. У вашому терміналі встановіть бібліотеку та її типи:
    pnpm install tail
    pnpm install -D @types/tail
  2. Згенеруйте новий сервіс у Nest: pnpm nest g service logReader (він створиться в папці src/log-reader і автоматично додасться до вашого AppModule).
  3. Вставте код, наведений вище, у ваш новий log-reader.service.ts.

Коли зробите, напишіть "готово", і ми запустимо ваш бекенд, увімкнемо гру і подивимось на магію в консолі!
