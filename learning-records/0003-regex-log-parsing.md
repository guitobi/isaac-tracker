# Парсинг логів гри за допомогою RegEx

Користувач успішно реалізував первинний парсинг логів гри:
1. Застосував регулярні вирази з групами захоплення (`capturing groups`) для вилучення динамічних значень (сіду забігу та ID персонажу).
2. Засвоїв різницю між самим об'єктом `RegExp` та результатом пошуку `RegExpMatchArray` через метод `String.prototype.match()`.
3. Вирішив проблему типізації `any` від сторонньої бібліотеки `tail` шляхом явного приведення типу аргументу колбеку до `string`.

## Evidence
Користувач самостійно виправив помилки присвоєння `any` та некоректного доступу до груп регулярного виразу у файлі `src/log-reader/log-reader.service.ts`.

## Implications
Ми навчилися витягувати сирі значення з логів. Наступним кроком є збереження цих даних у базу даних через Prisma, що вимагає:
- Створення зв'язку між `LogReaderService` та `RunsService`.
- Зіставлення ігрових ID персонажів (наприклад, `Variant 0` -> `Isaac`) з записами в БД.
- Визначення моменту закінчення забігу (перемога/поразка) для повного життєвого циклу запису `Run`.
