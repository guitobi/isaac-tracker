# Основи PrismaService та базовий CRUD

Користувач успішно засвоїв патерн інтеграції Prisma у NestJS:
1. Застосування Dependency Injection для впровадження `PrismaService` в інші сервіси (через конструктор).
2. Написання базових асинхронних запитів: `findMany()`, `findUnique()`, `create()`.
3. Використання оператора `include` для підвантаження зв'язків бази даних (Relation queries), розуміючи при цьому, що TypeScript автоматично оновлює тип результату.
4. Передачу DTO безпосередньо в об'єкт `data` методу `create`.

## Evidence
Користувач самостійно імплементував методи `findAll`, `findOne` та `create` у `RunsService`, використавши `include` для зв'язків `user` та `character`, і вірно передав `createRunDto` у метод `create`.

## Implications
У майбутніх сесіях ми можемо пропускати основи DI та синтаксис запитів, а одразу переходити до більш складних тем:
- Транзакції у Prisma.
- Мокання PrismaClient для Unit-тестування (Prisma Mocking).
- Складні фільтрації та пагінація.
